# מדיניות פרטיות - מבחן המציאות

**תאריך תחילה:** 03/09/2025

התוסף ל־Chrome "מבחן המציאות" מכבד את פרטיות המשתמשים. במסמך זה מוסבר אילו נתונים נאספים, כיצד נשמרים ולאילו מטרות נעשה בהם שימוש.  

## 1. איסוף נתונים
- התוסף מתעד את זמן השימוש באתרים שונים על מנת להציג סטטיסטיקות שימוש.  
- הנתונים נשמרים באופן מקומי בלבד באמצעות `chrome.storage.local`.  
- לא נאסף מידע אישי מזהה (PII).  

## 2. שימוש בנתונים
- הנתונים שנאספים משמשים אך ורק להצגת גרפים וסטטיסטיקות למשתמש.  
- הנתונים אינם נשלחים, נמכרים או מועברים לגורמים חיצוניים.  

## 3. הרשאות
- התוסף מבקש הרשאות גישה ללשוניות הדפדפן על מנת למדוד את זמן השימוש באתרים.  
- ההרשאות משמשות אך ורק למטרה זו.  

## 4. שמירת נתונים
- כל הנתונים נשמרים מקומית במחשב המשתמש.  
- הנתונים נמחקים באופן אוטומטי בסוף כל חודש.  

## 5. שליטה של המשתמש
- המשתמש יכול להסיר את התוסף בכל עת, והסרה זו תמחק לצמיתות את כל הנתונים שנשמרו באופן מקומי.  

## 6. שינויים במדיניות
- כל עדכון עתידי למדיניות הפרטיות יתפרסם עם תאריך תחילה חדש.

# Privacy Policy - Reality Test

**Effective Date:** 03/09/2025

The Chrome extension "Reality Test" respects your privacy. This document explains what data is collected, how it is stored, and for what purposes it is used.  

## 1. Data Collection
- The Extension records the time spent on websites in order to provide usage statistics.  
- Data is stored locally in `chrome.storage.local`.  
- No personally identifiable information (PII) is collected.  

## 2. Data Usage
- Collected data is used solely to display graphs and statistics to the user.  
- Data is not shared, sold, or transmitted to any third parties.  

## 3. Permissions
- The Extension requests access to browser tabs in order to measure time spent on websites.  
- These permissions are used only for the stated purpose above.  

## 4. Data Storage
- All data remains stored locally on the user’s computer.  
- Data is automatically deleted at the end of each month.  

## 5. User Control
- Users may uninstall the Extension at any time, which will permanently delete all locally stored data.  

## 6. Changes
- Any future updates to this Privacy Policy will be published with a new effective date.
